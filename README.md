# 💥 Minecraft Java Edition Explosive Cow Dung MOD (爆炸牛粪模组)

这是一个为 Minecraft **1.21.1 (Forge)** 开发的趣味模组！

## 📥 下载与安装
1. 前往本仓库右侧的 **Releases** 页面下载最新的 `.jar` 文件。
2. 确保你已经安装了对应版本的 **Minecraft Forge** (1.21.1)。
3. 将下载的 `.jar` 文件放入游戏目录下的 `.minecraft/mods` 文件夹中。
4. 启动游戏，扔出你的第一坨爆炸牛粪！

## 🐮 模组介绍
本模组添加了极具破坏力的“爆炸牛粪”。
牛粪不仅会炸，还会引发连锁反应。小心不要在自己脚下点燃它，否则你的好朋友可能会被炸飞！
